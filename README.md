# S.I.A — Special Intelligence Agency

A black-and-white, English-language, static GitHub Pages website for a Roblox intelligence-themed group.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository, for example `sia-website`.
2. Upload `index.html`, `style.css`, `data.js`, and `script.js` to the repository root.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**, and save.
5. Once deployed, the website will normally be available at `https://YOUR-USERNAME.github.io/sia-website/`.

## Edit articles, database entries, news, and operations

Open `data.js` and edit the entries inside `reports`, `organizations`, `news`, or `operations`. Use the same fields as the existing examples. Commit the file to publish your changes. All examples are placeholders, not claims of actual activity.

## Add your own logo

Upload your logo to the repository and replace the `<div class="seal" ...>...</div>` in `index.html` with `<img class="agency-logo" src="logo.png" alt="S.I.A logo">`. Add `.agency-logo{width:180px;max-width:80%;height:auto;margin:40px 0 28px}` to `style.css`.

## Privacy

Everything in a GitHub Pages site is public. Do not publish passwords, real personal information, private communications, or secret documents. Report only public Roblox activity, and label unverified information clearly.
